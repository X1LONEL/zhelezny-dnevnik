# Железный дневник

Дневник силовых тренировок и питания по персональной 9-недельной программе.

## Что умеет

**Тренировка.** Цикл вшит целиком: блок 1 (Full Body, дни A/B/C), блок 2
(Верх / Низ / Фулбоди), разгрузочная неделя. Приложение считает текущую
неделю от даты старта и само применяет её правила. По каждому упражнению
подсказывает цель по двойной прогрессии, показывает прошлый результат,
раскладку блинов на штанге и запускает таймер отдыха.

**Журнал.** История тренировок с разбором по подходам, выгрузка в CSV.

**Прогресс.** Графики рабочего веса и расчётного 1ПМ по каждому упражнению,
автоматические личные рекорды, тоннаж по неделям, подходы по группам мышц,
календарь регулярности, вес тела с подсказкой по калориям.

**Питание.** Трекер дня по меню из программы со счётчиками КБЖУ, быстрый
добор калорий, свои блюда. Средние калории и средний вес за неделю на общей
шкале — чтобы решение «добавить или убавить» опиралось на факт.

**Программа.** Справочник: структура цикла, дни, RPE, прогрессия, стартовые
веса, разминка и восстановление.

**Резервная копия.** Весь дневник одним JSON — перенос между устройствами
и бэкап. Восстановление добавляет недостающее и не затирает записанное.

## Две сборки из одного исходника

| | Artifact на claude.ai | PWA на GitHub Pages |
|---|---|---|
| Данные | облачная база артефакта | только это устройство |
| С любого устройства | да | нет, перенос через копию |
| Без сети | нет | да |
| Установка на телефон | нет | да, на домашний экран |

Артефакт установить на телефон нельзя: он живёт в песочнице внутри
claude.ai и не может зарегистрировать service worker. Поэтому сборка
делает второй выход — `dist/pwa/`.

## Установка на iPhone

1. Открыть адрес приложения **в Safari** (Chrome на iOS тоже умеет, но
   Safari надёжнее).
2. «Поделиться» → **«На экран «Домой»**.
3. Запустить с домашнего экрана: приложение откроется без адресной строки
   и дальше работает без сети.

Первый запуск должен быть с сетью — на нём кэшируются шрифты.

## Разработка

```
npm run build          # собрать dist/ (артефакт + PWA)
npm run check          # проверить сборку без записи
npm test               # слияние, резервная копия, прогрессия
npm run serve          # dist/pwa на http://localhost:8080
open dist/index.html   # посмотреть локально
```

PWA нельзя проверить через `file://` — service worker работает только по
http/https. Для проверки офлайна: `npm run serve`, открыть
`http://localhost:8080`, затем остановить сервер и перезагрузить страницу.

Зависимостей нет. Подробности архитектуры и ограничений платформ —
в `CLAUDE.md`.
